# images/exterior/ — Imagen Exterior del Proyecto

Coloca aquí la foto o render exterior del edificio.

## Archivo principal

```
building.jpg    — Render o foto exterior principal
```

Este archivo se usa en dos lugares:
1. Metadata Open Graph (`ogImage` en `metadata.ts`) — para previsualización en redes sociales
2. Opcionalmente como imagen de fondo del BuildingSelector (si se mueve a `public/building.png`)

## Especificaciones

- **Formato**: JPG
- **Dimensiones para OG**: 1200×630 px (16:9 o cerca)
- **Peso**: máximo 500 KB para carga rápida
- **Contenido**: debe mostrar claramente la fachada o perspectiva más atractiva del proyecto
